# L30 basemap assets

These local SVG basemaps are used by the L30 WWI, WWII, and Cold War visuals.

- `europe-blank-map.svg`: Wikimedia Commons, **Europe blank map.svg**, public domain / PD-Demis. Source: <https://commons.wikimedia.org/wiki/File:Europe_blank_map.svg>
- `world-blank-map.svg`: Wikimedia Commons, **Blank map of the world.svg**, CC0 1.0 public-domain dedication. Source: <https://commons.wikimedia.org/wiki/File:Blank_map_of_the_world.svg>

The application adds local labels and annotations; it does not hotlink the
source files.
